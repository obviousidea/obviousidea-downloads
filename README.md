# ObviousIdea download mirror

Backup distribution of ObviousIdea installers, hosted independently of our main website.

Download the installer you need from [Releases](https://github.com/obviousidea/obviousidea-downloads/releases). The SHA256SUMS.txt file lets you verify the download. Windows should also display a valid ObviousIdea digital signature.

The software remains subject to its existing licence and trial terms. This repository distributes installers; it does not publish the applications' source code or grant an open-source licence.

For assistance, email contact@obviousidea.com.

Main website: https://www.obviousidea.com/
